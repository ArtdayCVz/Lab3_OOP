### Лабораторна робота 3

Створити застосунок під Android, що відповідає наступним вимогам:
1.	Використати Kotlin/Java.
2.	Код повинен бути розміщений на віддаленому репозиторії. Історія змін повинна мати логічні commit-повідомлення, репозиторій має мати правильно налаштований gitignore файл.
3.	Для виведення повідомлень під час роботи застосунку використати засоби та підходи логування за допомогою правильно налаштованого Logger.
4.	Застосунок повинен мати гнучку підтримку декількох мов, використати засоби та підходи i18n наявні для розробки Andorid-застосунків.
5.	Студенти можуть запропонувати власний варіант завдання для цієї лабораторної роботи - за умови якщо вони близькі за складністю до вже наведених, і з обовʼязковим погодженням з викладачем.

Створити "Шашки", грають людина і комп'ютер.
